# Описания для новичков (data/guide)

Цель: человек, впервые играющий в D&D, создаёт персонажа без чтения книг. Нужны короткие
понятные описания каждого варианта выбора и советы «Быстрого создания» из книг.

## Правила

1. **Своими словами.** Сайт публичный, книги под авторским правом. Никакого копирования
   (валидатор ловит 10+ слов подряд из любой книги). Без художественного лора — суть для игрока.
2. **Ничего не выдумывать в правилах.** Факты (что даёт, какие характеристики важны, числа роста
   и веса) — только из книг. Советы (роль, сложность) — суждение, оно помечается в интерфейсе
   как совет; ставь их честно и сдержанно.
3. **Простой язык.** Пиши для того, кто не знает правил: «бьёт оружием в ближнем бою и держит удар»,
   а не «мили-дамагер с высоким АС». Термины — как в docs/translation-guide.md.
4. Источники текста: sources/books-text/<код>.txt (phb, xge, tce, scag, eepc, vgm, mtf), страницы `=== PAGE n ===`.
   id всех сущностей — из src/data/gen/*.json (classes, subclasses, races, subraces, backgrounds).
5. После каждого файла: `python -I tools/check_guide.py data/guide/<файл>` и исправить все ошибки.

## Форматы

### data/guide/classes.json
```json
{
  "fighter": {
    "tagline": "Мастер оружия и доспехов: надёжен в любом бою",
    "about": ["2–3 коротких предложения: что персонаж делает в игре, чем силён, что сложно"],
    "roles": ["урон", "защита"],
    "difficulty": 1,
    "primary": ["str", "con"],
    "quickBuild": {
      "abilities": ["str", "con", "dex", "wis", "cha", "int"],
      "background": "soldier",
      "spells": [],
      "note": "Вариант: ЛОВ вместо СИЛ для стрелка",
      "page": 72
    }
  }
}
```
- `tagline` ≤ 80 символов; `about` 1–3 элемента, каждый ≤ 260 символов.
- `roles` из: урон, защита, поддержка, лечение, контроль, разведка, универсал (1–3 шт.).
- `difficulty`: 1 — просто для новичка, 2 — средне, 3 — много решений во время игры.
- `primary`: основные характеристики класса (из таблицы классов книги).
- `quickBuild` — из раздела «Быстрое создание» класса в книге: `abilities` — порядок от самой
  высокой к самой низкой (все 6, сначала то, что книга советует сделать самым высоким, потом второе,
  остальные — разумно: ТЕЛ обычно третьей); `background` — id советуемой предыстории (если её нет в
  нашем каталоге — ближайшая по смыслу, в `note` напиши какая советуется); `spells` — id советуемых
  заговоров/заклинаний 1 уровня, если книга их называет; `page` — страница совета.

### data/guide/subclasses-<часть>.json (subclasses-a.json, subclasses-b.json — части сливаются)
```json
{ "battle-master": { "tagline": "Тактик с приёмами: подсечки, обезоруживание, команды", "about": ["1–2 предложения"], "roles": ["урон", "контроль"], "difficulty": 2 } }
```

### data/guide/races.json — и расы, и подрасы (ключ — id расы или подрасы)
```json
{
  "elf": { "tagline": "Изящные долгожители с острыми чувствами", "about": ["1–2 предложения"],
           "age": { "adult": 100, "max": 750 },
           "body": { "baseIn": 54, "heightDice": "2d10", "baseLb": 90, "weightDice": "1d4" } },
  "wood-elf": { "tagline": "Быстрые и скрытные лесные эльфы", "about": ["..."],
                "body": { "baseIn": 54, "heightDice": "2d10", "baseLb": 100, "weightDice": "1d4" } }
}
```
- `age`: возраст взросления и предел жизни (числа из описания расы).
- `body`: таблица «Случайный рост и вес» (Книга игрока, глава «Персонализация», и аналоги в других книгах):
  базовый рост в дюймах (4'8" = 56), куб модификатора роста, базовый вес в фунтах, куб модификатора веса
  (`null`, если в таблице «1»). Рост = baseIn + heightDice; вес = baseLb + heightDice × weightDice.
  Если таблицы для расы нет ни в одной книге — поля `body` нет.
- Подраса без своих чисел наследует расу — `age`/`body` у неё не пиши.
