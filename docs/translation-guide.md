# Перевод SRD 5.1 на русский — правила для переводчика

Источник текста — английский SRD 5.1 (CC-BY-4.0), нарезанный в `sources/slices/*.json`.
Русские книги в `sources/books-text/*.txt` (phb = Книга игрока, dmg = Руководство мастера,
xge, tce, scag, eepc, vgm, mtf) нужны ТОЛЬКО чтобы взять официальные русские
названия и термины. Текст из книг не копировать: описание переводится с английского SRD.

## Формат результата

- Вход: `sources/slices/<slice>.json` = `{ "<index>": { "name": ..., "desc": [...], ... , "_level": ..., "_class": ... } }`.
- Выход: файлы `data/ru/parts/<slice>.<NN>.json` (NN = 01, 02, ...), по 10–20 записей в файле,
  чтобы не писать гигантский файл за раз. Формат такой же: тот же `index`, те же поля
  (кроме служебных `_level`, `_class`, `_subclass` — их не копировать), значения на русском.
- Массивы (`desc`, `higher_level`) сохраняют число и порядок элементов: N абзацев → N абзацев.
- Markdown внутри строк (`|` таблицы, `###` заголовки, `**жирный**`, `- ` списки) сохранять,
  переводить только текст.
- Добавить поле `"_src": "phb:226"` — книга и номер PDF-страницы (строка `=== PAGE n ===`
  в txt выше найденного заголовка), где нашлось русское название. Если не нашлось — `"_src": null`
  и поле `"_name_check": "не найдено в книгах"`.
- После каждого файла: `python -I tools/check_translation.py <slice>` — проверяет JSON,
  покрытие индексов и совпадение чисел. Все предупреждения о числах исправить.

- Если правило исправлено по Книге игрока и числа поэтому расходятся с английским,
  добавить в запись `"_book_fix": ["desc"]` (список полей) — чекер не будет сверять в них числа.

## Числа и кубы — НЕ МЕНЯТЬ

- Все числа переносятся как есть. Цифры остаются цифрами, слова — словами
  (`three` → `три`, `3` → `3`). Нельзя менять футы на метры, фунты на кг.
- Кубы: `1d8` → `1к8`, `2d6 + 3` → `2к6 + 3`, `d20` → `к20`.
- Порядковые: `3rd level` → `3 уровня`, `5th-level spell slot` → `ячейку 5 уровня`.

## Названия

- Заклинания, предметы, умения, расы, особенности: брать официальное русское название
  из книги. Ищи в `sources/books-text/phb.txt` (заклинания — в главе заклинаний заголовками
  ЗАГЛАВНЫМИ буквами; умения — в главах классов), магические предметы — в `dmg.txt`.
  Записывай название в обычном регистре: «Огненный шар», а не «ОГНЕННЫЙ ШАР».
- Если в книге не нашлось — переведи сам, лаконично, и отметь `_name_check`.

## Стиль

Обращение «вы», как в книге. Сухо и точно, без украшательств. Ничего не добавлять
и не выкидывать: каждое правило из английского текста должно быть в переводе.
